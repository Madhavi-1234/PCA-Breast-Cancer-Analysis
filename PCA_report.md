# 🩺 PCA on Breast Cancer Dataset — Dimensionality Reduction & Visualization

This project applies **Principal Component Analysis (PCA)** on the Breast Cancer dataset to reduce dimensions, visualize clusters, and compare machine learning model performance before and after PCA.

---

## 📌 Features
- ✔️ Apply PCA on a real medical dataset  
- ✔️ Generate **2D & 3D PCA visualizations**  
- ✔️ Plot a Scree Plot to analyze explained variance  
- ✔️ Train ML models (Logistic Regression, SVM, Random Forest)  
- ✔️ Compare accuracy on:
  - Original dataset  
  - 2-Component PCA data  
  - 3-Component PCA data
